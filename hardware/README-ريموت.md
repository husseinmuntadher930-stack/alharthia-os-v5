# ريموت المعلم — القطع والتوصيل

## القطع

| القطعة | ملاحظة |
|---|---|
| Raspberry Pi Zero 2 W | موجود |
| شاشة Waveshare 5 إنج (HDMI + USB للمس) | موجودة |
| كيبل mini-HDMI ← HDMI (قصير) أو أداپتر | الصورة |
| كيبل micro-USB ← micro-USB | اللمس + طاقة الشاشة |
| كارت microSD ‏16GB+ | Raspberry Pi OS Lite 64-bit |
| بطارية LiPo 3.7V ‏2000–3000mAh | أو Power bank صغير بالبداية |
| بورد شحن ورفع 5V (MH-CD42 أو IP5306) | يشحن البطارية ويطلع 5V للـ Zero |
| مستقبل شحن لاسلكي Qi (ملف 5V) + شاحن Qi | للشحن اللاسلكي على الستاند |
| سويج انزلاقي صغير | تشغيل/إطفاء |
| براغي M2.5 × 6 مم (4) | تثبيت الـ Zero |
| موزّع USB صغير (OTG Hub بمنفذ micro-USB) | حتى تشبك اللمس + المايك + الفلاشة سوا (الـ Zero بيه منفذ بيانات واحد) |
| مايك USB صغير (اختياري) | ميزة «تكلّم ← نص» |

## التوصيل

> إذا تستعمل المايك أو الفلاشة: وصّل **الموزّع** بمنفذ USB الوسطي بالـ Zero، وبعدين اشبك عليه اللمس والمايك والفلاشة.


1. **HDMI:** منفذ mini-HDMI بالـ Zero ← HDMI بالشاشة.
2. **اللمس:** منفذ **USB** (الوسطي) بالـ Zero ← منفذ **Touch** بالشاشة.
3. **الطاقة:** بورد الشحن (OUT 5V) ← السويج ← منفذ **PWR IN** بالـ Zero.
4. **البطارية:** على مدخل BAT ببورد الشحن (انتبه للـ + و −).
5. **الشحن اللاسلكي:** مخرج مستقبل الـ Qi (5V) ← مدخل الشحن (IN) ببورد الشحن. الملف يلزق بجيبه بظهر الصندوق.

## التجهيز

على الصبورة: الإعدادات ← الريموت ← «ربط ريموت جديد».
على الـ Zero:

```
sudo bash remote-zero-setup.sh http://<IP الصبورة>:8770/
```

السكربت يطلب الرمز الي على الصبورة، وبعد `sudo reboot` الريموت يفتح وحده.

## الصندوق (طباعة 3D)

افتح `remote-case.scad` بـ OpenSCAD، قيس شاشتك وغيّر الأرقام بأول الملف، وصدّر 3 قطع: `front` و`back` و`stand`.
الستاند بيه جيب لشاحن Qi تحت، فالمعلم يحط الريموت عليه ويشحن وحده.
