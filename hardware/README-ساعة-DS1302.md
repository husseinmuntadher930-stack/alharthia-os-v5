# ساعة الوقت DS1302 (RTC)

حتى الصبورة تعرف الوقت الصحيح حتى لو طفت وماكو إنترنت (جدول الحصص والعد التنازلي يعتمدون عليه).

## البطارية

- **CR2032 (3 فولت)** بس. نفس بطارية لوحة الحاسبة.
- بطارية الساعة 1.5 فولت (LR44 / AG13) **ما تشتغل**: القطعة تحتاج 2 فولت على الأقل، وحجمها أصغر من المكان.

## التوصيل (الراسبيري 5)

| القطعة | الراسبيري 5 |
|---|---|
| VCC2 | دبوس 17 (3.3V) |
| GND | دبوس 14 |
| SCLK | دبوس 11 (GPIO17) |
| I/O | دبوس 13 (GPIO27) |
| RST | دبوس 15 (GPIO22) |
| VCC1 | لا توصله (هو البطارية) |

لا توصل VCC2 على 5V.

## الشغل

- خدمة `alharthia-rtc` تشتغل وحدها بعد التحديث.
- لمن يكون اكو إنترنت، تكتب الوقت الصحيح على القطعة كل 30 دقيقة.
- لمن تشتغل الصبورة بدون إنترنت، تاخذ الوقت من القطعة.
- تتأكد منها: **الإعدادات ← صحة الجهاز ← ساعة الوقت (DS1302)**، أو بالطرفية:

```
sudo python3 /opt/alharthia/alharthia_rtc.py read
```

## بديل أسهل

الراسبيري 5 بيه ساعة RTC من الأصل، بس تحتاج بطارية رسمية (Raspberry Pi RTC Battery) تنشبك على منفذ **BAT** (جنب منفذ USB-C). وياها ما تحتاج القطعة ولا أي توصيل.
